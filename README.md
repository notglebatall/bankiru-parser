# Парсер вкладов Banki.ru

Механический парсер собирает предложения из блока «Все предложения» на [странице вкладов Banki.ru](https://www.banki.ru/products/deposits/). Он читает данные карточек банков, включая скрытые до раскрытия предложения, и проходит все страницы списка. Модель и браузер для сбора данных не нужны.

## Запуск

    uv sync
    uv run jupyter lab src/run.ipynb
