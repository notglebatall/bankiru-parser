# Парсеры вкладов Banki.ru, Bankiros и Сравни

Механические парсеры собирают предложения из блока «Все предложения» на страницах [вкладов](https://www.banki.ru/products/deposits/) и [накопительных счетов](https://www.banki.ru/products/deposits/?type=14&special%5B%5D=14) Banki.ru. Они читают данные карточек банков, включая скрытые до раскрытия предложения, и проходят все страницы списка. Оба возвращают списки словарей с общими полями ставок, сроков и сумм. Парсер вкладов дополнительно возвращает условия пополнения, частичного снятия, пролонгации, капитализации, выплаты процентов, досрочного расторжения, открытия онлайн и плашки предложений. Для «Новых денег» и «Нового клиента» есть отдельные признаки и пояснения. Модель и браузер для сбора данных не нужны.

Код Banki.ru находится в `src/banki_ru/deposits.py` и `src/banki_ru/savings.py`, код Bankiros — в `src/bankiros/deposits.py`. Код Сравни — в `src/sravni/deposits.py`. В `src/run.ipynb` расположены вызовы всех трёх источников.

Bankiros собирает [каталог Москвы](https://bankiros.ru/deposit/moskva?from=mainpage) обычными HTTP-запросами, проходит все страницы и проверяет число предложений, групп банков и отсутствие повторов ID. В результат по умолчанию попадают только вклады; `collect_deposits(include_savings=True)` включает накопительные счета с признаком `is_saving_account`.

По умолчанию Bankiros дополнительно загружает каждый продукт: возвращает таблицу ставок в `rate_rows`, условия пополнения, снятия и пролонгации, капитализацию, выплату процентов, досрочное расторжение и текст дополнительных условий. Исходные подписи сроков и сумм сохраняются: столбцы таблицы могут обозначать периоды начисления процентов, а не варианты срока открытия вклада. Пустая ячейка ставки остаётся `None`. Эффективная ставка и бонусы не вычисляются из рекламных значений. Для быстрого сбора только карточек используй `collect_deposits(details=False)`. Подробный сбор делает отдельный запрос на каждый продукт и поэтому занимает больше времени. При ошибке парсер сообщает адрес продукта и не выдаёт неполный сбор за успешный.

Bankiros читает desktop `User-Agent` из `src/bankiros/userAgents.json`, расположенного рядом с парсером. `Accept-Language`, `Referer` и AJAX-заголовок пагинации задаются в коде.

При сборе Bankiros показывает прогресс загрузки страниц каталога и условий продуктов: число обработанных элементов, время работы и оценку оставшегося времени. На этапе условий также отображается текущий банк. `collect_deposits(progress=False)` отключает индикаторы.

Сравни собирает [каталог вкладов](https://www.sravni.ru/vklady/) с текущими фильтрами страницы (город, валюта и расчётная сумма). Исходные данные читает из HTML, остальные предложения получает одним запросом API с `limit`, равным счётчику каталога. Проверяет полноту и уникальность ID до фильтрации. Карточки с `fromMarketPlace=True` пропускаются: их ссылки ведут на отдельную страницу оформления без исходных данных условий. По умолчанию накопительные счета исключаются; `collect_deposits(include_savings=True)` включает их, `details=False` отключает отдельные запросы к продуктам.

По умолчанию Сравни возвращает также условия, лицензию банка, границы суммы, сроки и `rate_rows` для расчётной суммы и условий клиента. Это не полная матрица номинальных ставок: сохраняются исходные пояснения `rate_explanation`, условия клиента и параметры расчёта. Для накопительных счетов расчётный период не принимается за срок открытия. При ошибке подробного сбора возвращается исключение с адресом продукта.

## Запуск
